# 🔍 범인을 찾아라 시즌2 — 명제 추리 조별 게임

공통수학2 Ⅱ-2. 명제 (교과서 97쪽 '범인을 찾아라!' 확장판)
조마다 디벗 1대, 교사가 단계를 넘기며 진행하는 실시간 게임입니다. (Firebase Firestore 사용)

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 학생(조) 화면 |
| `teacher.html` | 교사 화면 — 방 만들기, 단계 진행, 조별 현황, 순위 (TV에 띄우기) |
| `cases.js` | 사건 4개의 이야기·증언·보기 (학생에게 보이는 내용) |
| `answers.js` | 정답·단서·해설·점수 규칙 (교사 화면에서만 불러옴) |
| `firebase.js` | Firebase 연결 설정 |
| `firestore.rules` | 보안 규칙 (콘솔에 붙여넣기용) |

## 처음 한 번만: Firebase 콘솔 설정

1. **Authentication → 시작하기 → 로그인 방법**
   - **익명** 사용 설정 (학생용, 이름·이메일 없이 입장)
   - **Google** 사용 설정 (교사용, 프로젝트 지원 이메일 선택)
2. **Authentication → 설정 → 승인된 도메인**에 추가
   - `mathsea5-arch.github.io` (GitHub Pages 배포 주소)
   - `127.0.0.1` (VS Code Live Server로 미리 볼 때)
3. **Firestore Database → 규칙** 탭에 `firestore.rules` 내용을 붙여넣고 **게시**
   - 이후 연결 테스트 페이지(firebase-test.html)는 더 이상 동작하지 않습니다(정상).

## 수업 진행

1. 교사: `teacher.html` 열기 → 구글 로그인 → **새 방 만들기** → TV에 방 번호와 QR 띄우기
2. 학생: QR을 찍거나 `index.html`에서 방 번호 입력 → **우리 조 번호** 선택 → 입장
3. 교사가 사건 탭(1~4)을 고르고 단계 버튼을 차례로 누름

| 단계 | 학생 화면 | 시간 |
|---|---|---|
| 1. 사건 소개 | 이야기와 증언 읽고 조별 토의 | 2~3분 |
| 2. 증언 해독 | 각 증언과 같은 뜻인 기호식을 **모두** 고르기 (대우도 같은 뜻!) | 3~4분 |
| 3. 범인 추리 | 정답 해독식이 단서로 공개 → 범인(+거짓말한 사람) 선택, 근거 쓰기 | 5~7분 |
| 4. 정답 공개 | 정답·해설·순위 공개 | 3분 |
| 5. 마무리 성찰 (게임 끝에 한 번) | 조원별 역할 선택 + 성찰 쓰기 | 3~4분 |

- **TV 모드(기본)**: 추리 중에는 조별 답과 정답이 숨겨지고, **정답 공개 단계에서는 조별 근거와 정오답이 TV에도 보입니다** (함께 근거 비교하기). 교사 노트북에서 'TV 모드 끄기'를 누르면 각 조의 답·근거·정답이 보입니다.
- 추리 중에는 순위표가 이전 사건까지만 반영되어, TV에 정답 여부가 미리 드러나지 않습니다.
- 수업이 끊기면 같은 방 번호로 **이어서 하기** 가능, 학생도 같은 방 번호·조 번호로 다시 입장하면 됩니다.

## 점수

| 항목 | 점수 |
|---|---|
| 증언 해독 (증언 하나를 같은 뜻 보기 빠짐없이, 틀린 것 없이) | +10 |
| 범인 정답 (사건 3은 거짓말한 사람까지) | +50 |
| 정답 맞힌 조 중 제출 순서 1·2·3등 / 4등 이후 | +30 / +20 / +10 / +5 |
| 교사가 주는 '근거 우수' (TV 모드를 끄면 버튼이 보임) | +10 |

## 사건 (모두 답이 하나로 정해지는지 컴퓨터로 전수 확인함)

| 사건 | 용의자 | 조건 | 답 | 핵심 개념 |
|---|---|---|---|---|
| 1. 급식실 푸딩 | 3명 | 범인 1명 | A | 대우 |
| 2. 미술실 물감 | 4명 | 범인 2명 | C, D | 대우 + 삼단논법 (교과서와 구조는 같고 답은 다름) |
| 3. 음악실 악보 | 4명 | 범인 1명, 1명이 거짓말 | C (거짓말도 C) | 드모르간, 모순 |
| 4. 과학실 노트 | 5명 | 범인 3명 | A, B, E | 필요조건, '또는' = 조건문 |

## 참고

- 입장할 때 조원 학번·이름을 입력합니다. 명단은 별도 컬렉션(`members`)에 저장되며 **방을 만든 교사만 읽을 수 있습니다** (다른 조 학생은 볼 수 없음).
- 게임이 끝나면 교사 화면의 **[5. 마무리 성찰]**을 누릅니다. 각 조가 디벗을 돌려 가며 조원별로 '오늘 맡았던 역할'(여러 개 선택)과 성찰(10자 이상)을 저장합니다. 성찰도 교사만 읽을 수 있습니다.
- 교사 화면의 **[기록 내려받기 (엑셀)]**: 학생 1명당 1줄로 조·학번·이름·사건별 해독·고른 답·정오·정답 순위·근거·근거 우수·총점·역할·성찰이 담긴 CSV를 받습니다.
- 학생 개인정보가 외부 서비스(Firebase)에 저장되므로, 학기 말에 기록을 내려받은 뒤 Firebase 콘솔에서 해당 방 데이터를 삭제하는 것을 권장합니다.
- `answers.js`는 교사 화면에서만 불러오지만 공개 저장소에 올라가므로, 마음먹고 찾으면 볼 수 있습니다. 수업용 게임으로는 충분하지만 시험에는 쓰지 마세요.
